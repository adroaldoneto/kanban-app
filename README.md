# kanban-app

Este repositorio contem a especificacao de um modulo Kanban online para ser integrado a um sistema de escala existente com autenticacao Firebase.

Como o projeto principal nao esta presente neste workspace, a entrega aqui foi organizada como documentacao pronta para implementacao:

- `docs/kanban-especificacao-firebase.md`: visao funcional e tecnica do modulo
- `docs/prompt-implementacao-kanban.md`: prompt completo para implementar a solucao no sistema real

Principais capacidades definidas:

- autenticacao via Firebase integrada ao sistema atual
- quadro Kanban online com arrastar e soltar
- vinculo de cards com turnos, equipes e escalas
- relatorio geral em formato Gantt
- relatorios diarios exportaveis em PDF e imagem
- disparo manual e automatico por e-mail
